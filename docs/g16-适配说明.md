## 相对 g15 的改动
1. `package.json`：version `1.1.71-g15` → `1.1.71-g16`；description 改为「适配 DSH Go 1.0.16（内置 DSH 0.2.2-rc.1）」。
2. `lib/core.js` #86（SESSION_STEER_ALWAYS_FOLLOWUP）新增 g16 专用锚点：
   DSH Go 1.0.16 在 `case "steer":` 首行插入了
   `this.ctx.get("sessionPersistence")?.dshGoDeletion?.assertAdmit(agent.id);`，
   原 4 行字面锚点整段 miss（补丁仍报 applied，行为却退回 `agent.steer()`）。
   新 pattern 把该守卫行纳入锚段，replace 后 `agent.steer(message);` 换成
   `agent.followup(message); // [dsh-purge-86] queue steer → next-turn`。
3. 其余 84 条补丁在 1.0.16 上锚点未漂移，无需改动。
